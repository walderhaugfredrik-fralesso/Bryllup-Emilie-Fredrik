# Bryllupsapp

En enkel webapp for bryllupsgjester med program, sted, praktisk info, transport, Q&A, nedtelling og lenke til spørreskjema.

## Endre innhold

- Bytt navn, dato og sted i `index.html`.
- Endre nedtellingsdato i `script.js`.
- Bytt bilde ved å erstatte `assets/wedding-hero.png`.
- RSVP lagres lokalt i nettleseren i denne versjonen. Hvis dere vil samle svar fra gjester, kan skjemaet kobles til for eksempel Airtable, Google Sheets, Supabase eller en liten backend.

## Åpne appen

Åpne `index.html` i nettleseren. Når appen legges på en vanlig webserver, blir den også installasjonsvennlig på mobil.
